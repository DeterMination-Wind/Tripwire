# Tripwire / 地理围栏

## 中文

> 把地图上的关键边界变成可观察的警戒线。

Tripwire 让你在 Mindustry 地图上画出警戒线，指定关注的单位和穿越方向。当目标越过边界时，它会用屏幕提示、聊天或地图标记提醒你。

它适合基地防守、关键通道监视和多人协作。警戒线与报警都只存在于本地客户端，不需要服务器安装；MindustryX 还可以提供悬浮绘制和删除按钮。

### 开始使用

安装并启用模组后，在 设置 → 控制 中绑定 Tripwire 按键。创建围栏，选择需要监视的单位和穿越方向，再到 设置 → 模组 → Tripwire 调整提醒方式。

默认不绑定按键，避免安装后占用已有控制。

## English

> Turn important map boundaries into visible warning lines.

Tripwire lets you draw warning fences on a Mindustry map, choose which units to watch, and select the crossing direction that matters. When a watched unit crosses the fence, the client can notify you with a toast, chat message, or map marker.

It is useful for base defense, chokepoint monitoring, and multiplayer coordination. Fences and alerts are local to the client and require no server installation. MindustryX can additionally provide floating draw and delete buttons.

### Getting started

Enable the mod and bind the Tripwire controls under Settings → Controls. Create a fence, choose the watched units and crossing side, then adjust alert behavior under Settings → Mods → Tripwire.

No key is bound by default, so installing the mod does not take over an existing control.
