Tripwire adds clear geofence alerts to Mindustry. Draw warning lines on the map, choose what should be watched, and get notified when enemy units cross the side you care about.

## What It Does

- Draw tripwire fences directly in-game.
- Pick the crossing direction for each fence.
- Choose which unit types should trigger alerts.
- Show fence visuals on the map and minimap.
- Receive center-screen warnings, chat alerts, and map markers.
- Batch rapid multiplayer warnings into readable chat messages.

## Getting Started

Install the latest release, enable Tripwire in the mod list, then set the Tripwire controls in Settings. Create a fence, select the watched units and crossing side, and adjust alert timing or display options from the Tripwire settings page.

## Notes

Tripwire is made for active defense awareness. It keeps alerts visible without flooding the screen, and its chat merge window can be tuned from fast reactions to quieter grouped reports.

# Tripwire 地理围栏

Tripwire 为 Mindustry 添加清晰的地理围栏报警。你可以在地图上画出警戒线，选择需要监视的单位，并在敌方单位从指定方向穿越时收到提醒。

## 功能

- 在游戏内直接绘制围栏线。
- 为每条围栏选择穿越方向。
- 选择哪些单位类型会触发报警。
- 在地图和小地图上显示围栏。
- 通过屏幕中央提示、聊天栏消息和地图标点提醒。
- 多人服务器中的连续报警会自动合并成易读的聊天消息。

## 开始使用

安装最新版本，在模组列表中启用 Tripwire，然后到设置里配置 Tripwire 控制键。创建围栏后，选择需要监视的单位和穿越方向，并在 Tripwire 设置页调整报警时间与显示选项。

## 说明

Tripwire 面向主动防守提醒。它会尽量让报警保持可见，同时避免刷屏；聊天合并时间可以按你的节奏调快或调慢。
